## 直接使用

仅使用的话，从[最新版下载页](https://github.com/Liquidzk/LQ-yysls-logs/releases/latest) 下载 `win-x64.zip` 客户端压缩包，完整解压后，安装 Npcap，**以管理员身份运行** `燕云Logs.exe` 即可，无需自行构建。各功能操作见压缩包内的 `使用说明.md`。

从 0.4.21 起，可在“设置 → 客户端更新”中检查、下载并重启更新。

在线查看：[客户端使用说明](docs/客户端使用说明.md)。

### 安装 Npcap

Npcap 是实时采集所需的依赖，安装很简单

1. 打开 [Npcap 官网下载区](https://npcap.com/#download)，下载 **Npcap installer**（安装程序，不是 SDK、源码或调试文件）。
2. 运行安装程序，允许 Windows 管理员权限提示，阅读许可后按提示安装；一般保持默认选项即可。无需开启无线监听模式，也无需另装 Wireshark。
3. 若安装器要求重启 Windows，先重启；否则完全退出并重新打开燕云 Logs。更新已有驱动时，先退出正在采集的程序。
4. 手动启动游戏并进入角色，在客户端选择进程，点击“绑定并开始采集”。

安装选项和故障处理见压缩包内 `使用说明.md` 的“安装 Npcap”章节。
