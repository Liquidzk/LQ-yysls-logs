# 燕云 Logs 客户端使用说明

## 安装与启动

1. 从 [Releases](https://github.com/Liquidzk/LQ-yysls-logs/releases) 下载 `win-x64.zip` 客户端压缩包。
2. 完整解压，双击 `燕云Logs.exe`。请保留同目录下的其他文件。
3. 实时采集需要本机已安装 Npcap，客户端压缩包不包含该驱动；仅复盘已有记录时无需开始采集。

启动后不会自动绑定游戏或扫描游戏日志。切换客户端版本时，先通过菜单“燕云 Logs → 退出”完全退出旧版，再打开新版；游戏无需重启。

## 实时采集

1. 手动启动游戏并进入角色。
2. 在“实时采集”页点击“刷新”，根据程序路径和 PID 选择游戏进程。
3. 点击“绑定并开始采集”，等待状态显示“采集已就绪”。
4. 点击“打开悬浮窗”，即可在游戏中查看实时统计。
5. 结束记录时点击“停止并保留记录”。关闭主窗口或退出客户端也会停止采集，已保存的记录保留。

游戏退出或重启后，需要刷新进程列表并重新绑定。若提示无读取权限，退出客户端后右键选择“以管理员身份运行”，再手动绑定。

## 悬浮窗

### 统计与外观

- 点击“输出”“治疗”“承伤”切换统计项目，查看队员累计值和每秒数值。
- 拖动标题栏移动窗口；悬浮窗保持置顶，建议配合游戏的窗口化或无边框模式使用。
- 点击齿轮调整背景透明度、文字大小和 Boss 血量显示，设置会自动保存；“恢复默认”可重置外观。
- 点击 `↗` 返回主窗口复盘，点击 `−` 隐藏悬浮窗。

### 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Shift+F8` | 切换鼠标穿透；开启后鼠标操作会落到下方游戏窗口 |
| `Ctrl+Shift+F9` | 显示或隐藏悬浮窗 |
| `Ctrl+Shift+F10` | 实时悬浮窗显示时，收藏当前采集会话中最近结束的战斗 |

需要点击悬浮窗按钮时，先关闭鼠标穿透。收藏快捷键被占用时，设置中会提示，可改用悬浮窗的 `☆` 按钮。

### 战斗计时

计时自动开始和结束，无需手动按表。胜利或战斗结束通知到达后先停表，收到匹配的服务器结算时长后再校准，每秒统计同时更新。

| 状态 | 含义 |
| --- | --- |
| 战斗计时 | 已收到开战依据，正在计时 |
| 估算计时 | 缺少明确开战通知，以累计统计变化估算起点 |
| 已胜利 · 待校准 | 已收到胜利通知，等待服务器结算时长 |
| 服务器结算 | 已使用服务器给出的战斗时长 |
| 开战时间未知 | 中途绑定等情况下，缺少本场起点 |

鼠标停留在计时区域可查看来源。停止采集或失去数据更新时计时暂停；已结算的成绩保留至下一次开战。

### Boss 血量

在齿轮设置中选择“百分比”或“真实数值（当前／上限）”；真实数值可以使用原始单位或“万”。

愁铃客的肉体、灵魂分别显示两条血量，并显示百分比差。鼠标停留在血条上可查看完整数值。未收到完整血量时显示等待；采集停止或连接中断时保留末次观测。

## 捕获记录与战斗复盘

点击“捕获记录”，在左侧选择记录：

- **战斗**：一场已识别的战斗，适合查看成绩和时间线。
- **完整采集会话 · 包含 N 场战斗**：整次采集的入口，可包含多场战斗以及战斗前后的观测。
- **完整采集会话 · 未分段观测**：已有事件，但尚未识别出独立战斗边界。

仅有初始化信息的空会话不会列出。点击列表旁的刷新按钮可重新读取记录；“解析已有捕获目录”可添加本软件或参考软件的 `capture` 目录、会话目录或包含 `sessions` 的目录，导入不会移动原始文件。

| 页面 | 用法 |
| --- | --- |
| 队伍统计 | 查看服务器累计输出、治疗及每秒统计 |
| 技能观测 | 查看技能命中通知的次数、累计值及首次／末次时间；点击技能查看对应事件。服务器技能结算单独列出 |
| 原始事件 | 按角色、事件类型和名称／编号筛选，翻页查看；点击一条事件查看详细字段 |
| Buff 观测 | 查看 Buff 添加、更新、移除等通知，按角色和编号筛选 |
| 战斗时间线 | 对照 DPS、Buff 覆盖和动作顺序，操作见下节 |

## 战斗时间线

先选择一场战斗，再点击“战斗时间线”。如果选中完整会话，页面会提示先选择具体场次。

### DPS 曲线与时间范围

“DPS 查看角色”选择全队或个人；选个人时同时显示全队和该角色曲线。平滑窗口可选 1、3、5、10 秒。移动鼠标可查看时间点和数值。

输入起止秒数并应用可查看局部，点击“全场”恢复。下方覆盖率和动作轨道使用同一时间范围。

### 添加和排列时间线

1. 展开“选择加入时间线组的内容”。
2. 选择“队员 Buff”“Boss Buff／Debuff”或“玩家动作”。
3. 按角色／目标、名称或编号筛选，勾选所需行加入组中；批量勾选与取消只作用于当前筛选结果。
4. 拖动每行左侧的 `⠿` 调整顺序，三种类型可以混排。也可聚焦手柄后按 `Alt+↑`／`Alt+↓` 移动。
5. 取消勾选可移除单行；“清空时间线组”移除全部行，“恢复默认选择”恢复组内默认内容。

默认加入各玩家动作，以及已观测到的增伤 霖 `#1058032`、增伤（阴阳）`#98752`、崩解 `#10245332`；Boss 效果按需勾选。愁铃客肉体与灵魂可分别选择。

布局和动作明细角色选择按战斗保存，最多保留 15 场布局。顶部 DPS 角色选择、时间线组和底部明细的角色选择相互独立。

### 查看覆盖和动作

- **Buff 覆盖条**：右侧百分比按当前时间范围计算，重叠来源只计算一次。点击区间查看接收者、来源、层数和起止时间。条纹表示起止边界不完整。
- **玩家动作条**：实色表示已观测到起止的动作，条纹表示边界不完整；命中通知单独保留。点击动作条查看时长与结束依据，点击通知点查看附近事件。
- **组内动作筛选**：可选择施放与命中、只看施放或只看命中，也可搜索技能。

### 动作次序明细

在最下方勾选任意多位角色，查看各自依次的技能、开始／结束时间、动作时长和前次间隔。明细的技能搜索与组内动作搜索相互独立。

切换为“待复查间隔”可按间隔从长到短查看，并设置最小秒数。点击“查看附近”会缩小上方时间范围，并将对应玩家动作加入时间线组。

动作时长表示服务器同步中观测到的占用区间，不等同客户端动画的前摇或后摇。空档需结合走位、机制、不可攻击阶段和记录缺失判断，不能直接当作散步时间。

## 收藏战斗

捕获记录及本地 CLv2 列表中的 `☆`／`★` 可收藏或取消收藏；勾选“只看 ★ 收藏”筛选记录。捕获战斗详情也可使用“收藏战斗”按钮。

实时悬浮窗显示时，按 `Ctrl+Shift+F10` 或点击悬浮窗 `☆`，可收藏当前采集会话中最近结束并保存的战斗。重复操作保持收藏，不会取消；界面会提示成功或未能收藏的原因。

## 本地 CLv2 日志

### 导入、扫描与选择

点击顶部“本地 CLv2”，无需绑定游戏即可复盘。

- 点击“导入日志”，选择游戏保存的 `.bin` 文件或 `.zip` 日志包；可多选，单个文件上限为 64 MB。
- 通过菜单“燕云 Logs → 选择游戏日志目录…”设置目录，再点击“扫描”读取已有日志。
- 在左侧按日期、场景名称或编号搜索并选择战斗。

### 分析、播放与笔记

选择“观察对象”和分析区间，在“战斗时间线”“技能复盘”“Buff 覆盖”“伤害与治疗”“事件记录”之间切换。点击技能释放记录，可查看当时的 Buff、来源、层数和技能阶段。

拖动底部时间滑块查看当前状态、多人同期快照及最近事件；点击播放按钮按所选速度推进。输入复盘笔记并点击“添加标记”，即可将笔记保存在当前时间点。

点击“复盘统计窗”查看所选日志的统计；它展示的是本地复盘数据。

### 合并视角与导出

在列表中勾选同一场战斗的 2～12 份日志，点击“合并勾选视角”。设置各视角的时间偏移后打开合并复盘，正数表示向后移动该视角。

点击“导出日志包”导出当前报告涉及的原始日志。多视角同时间戳的先后顺序与重复回报可能存在不确定性，应结合事件详情核对。

## 名称查询

在捕获记录界面点击右上角“名称表”，选择 Buff、技能／动作、场景或 NPC 模板，按名称或原编号搜索。可筛选已映射、待恢复或客户端未命名的条目，并查看来源。

本地 CLv2 页使用“名称映射”入口。未取得名称的条目保留原编号；`#98752` 的复盘显示名为“增伤（阴阳）”。

## 记录保存与数据含义

点击“打开记录目录”进入网络采集的 `captures` 目录；菜单“燕云 Logs → 打开战斗归档”打开应用数据目录。`captures/sessions` 保存各次采集及其分段战斗，收藏独立保存。

压缩事件文件为 `.jsonl.ylz`，选择所在捕获目录即可复盘，无需手动解压或额外安装压缩工具；旧 JSONL 记录也可读取。客户端不会自动上传记录。

复盘时请区分这些数值：

- 服务器累计统计、逐次通知和技能结算是不同视图，不能相加。
- 网络时间线使用本机接收时间；命中次数不等于施法次数，延迟命中可能在动作结束后到达。
- Buff 未观测到不等于没有，队友私有状态可能不完整；旧记录缺失的事件不会凭空补出。
- 未知数值与实际的零分开显示；本地 CLv2 的“观测每秒”不代表完整全队 DPS，目前未提供 rDPS。

## 常见问题

| 情况 | 操作 |
| --- | --- |
| 找不到进程或读取权限不足 | 确认游戏已启动，刷新列表；需要时退出客户端并以管理员身份运行后重新绑定 |
| 游戏重启或连接变化 | 游戏重启后手动重新绑定；连接变化时等待重新校验，查看状态栏原因 |
| 等待采集恢复、没有游戏数据或协议校验失败 | 确认已进入角色，查看状态栏具体原因；记录目录中的初始化资料可用于排查 |
| 提示游戏版本尚未适配 | 先手动选中游戏进程并尝试绑定，再以管理员身份运行发行目录内的“检查当前游戏版本.cmd”；结果保存在 `captures/compatibility`，需后续适配 |
| 角色名或 Boss 血量缺失 | 保持采集后切换场景或重新进入副本，等待完整实体快照；已遗漏的历史数据不保证能补回 |
| 时间线提示选择战斗 | 从完整采集会话中选择具体场次 |
| 收藏快捷键无效 | 确认实时悬浮窗正在显示且当前会话已有结束战斗；快捷键冲突时使用 `☆` 按钮 |
| 切换版本后仍是旧客户端 | 从菜单完全退出旧版，再启动新目录中的程序 |
