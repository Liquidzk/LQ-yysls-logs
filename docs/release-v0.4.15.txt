燕云 Logs 0.4.15

文档整理版
- README 改为 Markdown，保留直接下载使用说明与简洁构建步骤。
- 客户端使用说明按功能整理，覆盖采集、悬浮窗、Boss 血量、战斗复盘、时间线、收藏及本地 CLv2；发行包附带“使用说明.md”。
- 功能沿用 0.4.14，包含可拖动排序的时间线组及空采集会话显示修复。

下载与使用
下载 LQ-yysls-logs-v0.4.15-win-x64.zip，完整解压后运行燕云Logs.exe。仅使用客户端无需下载源码包或自行构建；实时采集需要本机已安装 Npcap。
切换版本时，从旧客户端菜单“燕云 Logs → 退出”后再启动新版。游戏无需重启，采集仍需手动选择进程并绑定。

附件
- win-x64.zip：Windows x64 客户端。
- source.zip：对应源码，包含 Kagerou 子模块。
- release-manifest.json：构建来源及文件清单。
- SHA256SUMS.txt：附件校验值。
