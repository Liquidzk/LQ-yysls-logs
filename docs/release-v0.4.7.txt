燕云 Logs 0.4.7 测试版

战斗时间线新增每个人的动作持续条、动作顺序表和待复查间隔列表。
修复玩家动作缺少结束观测：跟踪技能同步队列条目的建立和移除，关联同一次动作，显示持续时间和前次间隔。
实色表示起止完整，条纹表示边界不全；命中继续单独显示。支持角色、技能、区间筛选，间隔按最长优先排列，点击“查看附近”联动 DPS、Buff 和动作。

动作时长使用服务器同步的收包时间，不等同客户端动画帧或前后摇。空档需结合走位、机制与可攻击阶段复查，不自动判定为散步。
场景切换、离场、快照、连续同技能和缺失结束分别处理，不使用最后一次命中或固定技能时长推算。
旧记录可读取独立校验后的 action-reprocessed.jsonl，原始记录保留；没有结束依据的旧动作继续标记未知。

验证：50 项 JavaScript 测试、79 项 Python 测试，TCP/KCP 端到端验证与真实五人战斗回放。
本机已补解的会话恢复 21,450 条玩家结束信息；一场愁铃客记录的 308 个动作中，305 个具有完整起止。

升级：退出旧客户端，运行完整解压的新版。已有战斗记录继续使用；实时采集仍需手动选择游戏进程。无需重启游戏。
源码、客户端与校验文件附于本 Release；不包含个人日志和会话资料。
