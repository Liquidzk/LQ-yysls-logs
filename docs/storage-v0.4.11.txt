0.4.11 事件存储与核验

采集与读取
- Node 自带 zlib level 3 压缩，Python 标准库解压；发行包不增加外部工具。
- 各 .jsonl 事件流和每场统计快照写为 .jsonl.ylz。latest.json、health.json、battle.json 等当前状态继续可直接读取。
- 约 256 KiB 或 500 ms 刷新一块；单条事件不跨块。正常停止先刷新尾块。
- 文件只追加，不轮换或搬动已写块。压缩不会按 Buff ID 合并事件，不丢失叠层、刷新、来源和实例。
- 12 字节块头：ASCII YLZ1、压缩长度 uint32 LE、解压长度 uint32 LE，随后为含 Adler-32 校验的 zlib 数据。各块独立，没有外部字典。
- 当前写入器单条事件最大 4 MiB，读取器单块上限 8 MiB；解压长度受限。校验失败不推进索引；未写完的尾块等待下次读取。已关闭记录的残缺尾块会计入 skippedRows，之前的完整块保留可读。
- 进程异常退出仍可能丢失尚在内存中的尾块；正常停止会刷新。文件缓存写入不等于断电持久化保证。

轻量索引
- capture-index-v2.sqlite3 保存时间、参与者、技能/Buff ID、伤害数值、排序字段与事件位置，不保存 payload JSON。
- 原 JSONL 用字节偏移；压缩流用块偏移、解压后的行偏移及长度。每次请求最多缓存 16 MiB 已解压块。
- 数值字段沿用 SQLite JSON 的数值转换，避免切换格式造成小数精度和累计值差异。
- 同一时刻的不同事件以流内序号保留；离线补解动作仍优先于原动作，不重复计数。
- 每轮最多索引每条流约 32 MiB 解压数据，块完整后提交检查点。长会话逐轮完成索引；进度变化时不沿用未完成时间线缓存。
- 文件身份、开头/检查点内容和同尺寸改写检测用于重建失效位置；新旧格式均可导入。
- 旧 capture-index.sqlite3 原样保留供旧版回退使用，本版不再追加它。历史原文件不迁移、不删除；因此升级本身不会立即缩小历史目录。

本机验证
- 57 项 Node、93 项 Python 测试；覆盖 Unicode、同时刻重复、自动刷新、结束刷新、半块续写、关闭后的残缺尾块、校验损坏、超限解压、索引格式切换、动作补解优先级及数值精度。
- 使用实际 Node 写入器，以 500 ms 刷新节奏压缩真实记录，由 Python 读取器完整解压；所有事件流逐字节 SHA-256 一致。
- 真实五人样本：16,219,938 字节事件 → 1,466,328 字节；26,615,808 字节旧索引 → 3,715,072 字节新索引。
- 1/3/10 秒 DPS 窗口、Buff 覆盖、动作持续与顺序、109 页事件、逐人查询和统计均与 v0.4.10 返回值一致。
- 约 150 分钟会话：1,047,861,920 字节事件 → 103,231,991 字节；9 个流哈希一致；761,423 条被选用的事件完整索引，17 轮约 17.83 秒，索引 221,593,600 字节。两套动作流均保留，只索引补解流。
- 完整会话离线模拟的 46,784 次写块，95% 耗时约 0.20 ms，单次最大约 2.55 ms；这是本机离线测量，不是游戏帧率承诺。
- 打包后的引擎直接读取仅含压缩事件流的真实战斗，桌面显示五人动作和 Buff 覆盖；TCP、KCP、缓存角色名的完整合成采集链路通过。

尚未改变的空间来源
原始 transport.private.tsv 仍保持原样，它兼作解析队列与问题复查证据；本版不对其截断、轮换或压缩。历史中的重复身份事件不会被本次验证删除；新的采集已沿用 0.4.10 的身份去重。
