燕云 Logs 0.4.6 测试版

修复组队进入沉棺柏梦等副本时 Boss 血条消失、单人却正常的问题。
组队加载中，Boss 的初始血量可能先于副本状态实体到达；0.4.5 会把这个新 Boss 当作旧场景状态清掉。
现在改为在引擎完整场景数据到达时清理旧状态，保留随后创建的 Boss，兼容两种实体加载顺序。
退出副本仍清除旧血条；普通场景属性更新不影响血量；愁铃客的肉体与灵魂继续分别更新。

验证：同一份真实组队捕获从仅 1 条初始 Boss 血量恢复为 1,300 条有效记录，直到归零；同时核对了单人入场、离场和切换另一 Boss。
49 项 JavaScript 测试、66 项 Python 测试，以及真实协议 TCP/KCP 端到端回放通过。

升级：退出旧客户端后运行完整解压的新版，手动选择游戏进程并开始采集。无需重启游戏；进入副本后接收完整 Boss 快照。
已有战斗记录保留；源码与客户端均附于本 Release，不含个人日志、原始传输记录和会话资料。
