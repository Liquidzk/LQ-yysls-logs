燕云 Logs 0.4.2 测试版

Windows x64 独立桌面客户端，手动选择游戏进程后开始采集；提供实时悬浮统计和本地战斗复盘。

本版内容
- 自动开战计时：优先使用开战状态；收到服务器结算时长后校准计时及 DPS/HPS，并保留到下一场。
- 增加 KCP 与已验证的 UU IPv4 UDP 转发解析；初始化和正式采集共用连续捕获，遇到缺包或冲突停止解码。
- 修复当前游戏版本的技能、Buff 与角色名称观测，保留原始角色 ID；支持本地 CLv2 导入。
- 燕云专用 Kagerou 悬浮窗，支持置顶、透明度、鼠标穿透；运行界面移除无关 FF14 内容。

下载与使用
1. 下载 LQ-yysls-logs-v0.4.2-win-x64.zip，完整解压后运行“燕云Logs.exe”。不要只取出 exe。
2. 实时采集需要自行安装 Npcap；驱动不包含在压缩包中。
3. 手动启动游戏并进入角色，在客户端刷新列表、选择进程、点击“绑定并开始采集”。
4. 读取权限不足时退出客户端，再右键以管理员身份运行。默认不绑定游戏、不自动采集。
5. 旧版用户应通过“燕云 Logs → 退出”完全退出旧客户端后再启动新版。

发布包不包含个人 desktop.local.json、战斗库、角色缓存、抓包或连接状态。默认使用当前 Windows 用户的应用数据目录；已有自定义数据目录的用户，可在本机保留原配置以继续使用原战斗库。

验证与已知范围
- 41 项 Node 测试、46 项 Python 测试通过；TCP 与 KCP 使用合成数据完成端到端验证。
- 真实 KCP 样本离线解析通过，持续在线采集的用户验收尚未完成，因此标为测试版。
- 队友私有 Buff、完整施法顺序和 rDPS 尚未验证；通知次数不等于施法次数。
- 实时计时可能受接收延迟影响，最终以收到的服务器结算时长为准；中途绑定且缺少开战依据时不推算精确时长。
- 游戏更新可能需要重新适配；未知版本不跳过校验。
